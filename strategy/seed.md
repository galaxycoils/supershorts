# Seed Plan (Day 0)

This file is the bootstrap plan the daily run reads on the first
iteration. After day 1 it is no longer referenced — `latest.md` becomes
the input.

## Hypothesis for first run

The Brainrot mode has the highest engagement-per-dollar ratio (zero
variable cost, sub-60s render, native short-form algorithm fit). Lead
with it.

## Today's experiments (proposed for day 1)

1. Ship 3 Brainrot Shorts in the same niche (e.g. "weird historical
   facts") with three different hook structures:
   - **Question hook**: "Did you know that [shocking fact]?"
   - **Pattern interrupt**: open with a number or contradiction —
     "Everyone thinks X. They're wrong."
   - **Loop hook**: open and end with the same line so the loop
     reinforces the watch
2. Same voice (Adam) across all three to control for voice variable.
3. Same gameplay background to control for visual variable.
4. Post staggered: 8am / 12pm / 8pm local time.

## What to measure

- 24-hour retention curve per video (CTR, AVD%, like rate, comment rate)
- Which hook produced the best AVD%
- Which timeslot produced the best initial velocity
