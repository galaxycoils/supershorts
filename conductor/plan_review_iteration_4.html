Risk Assessment

Pexels API Rate Limiting Medium

Frequent "Auto-generate" calls might exhaust Pexels API keys quickly.

Mitigation: Aggressively cache Pexels URLs and use local viral fallback pool as primary during high-frequency runs.
Tone Hallucination Low

LLM might interpret "Funny" style instructions too literally, breaking JSON output format.

Mitigation: Wrap tone instructions in strict system message; keep JSON schema instructions as the final instruction.
TCM Mode VideoOptions Mismatch High

Plan mentions failure but doesn't specify which argument is missing. Mismatch in threads or fps could crash moviepy.

Mitigation: Verify VideoOptions footprint against all compose_video signatures before applying.
